# 深夜便利店：IAA 核心机制灰盒

这是一个零依赖、移动端优先的 Web 原型，用来验证类似《猛鬼宿舍》《赵云与阿斗》的底层情绪骨架，而不是复制它们的题材或具体玩法。

## 试玩目标

玩家在 90 秒内经历：

1. 自动经济开始滚动；
2. 明确敌人接近并攻击卷帘门；
3. 在继续建货架和立刻补防御之间取舍；
4. 通过相邻布局形成能力质变；
5. 从濒临失败进入短暂反杀。

## 操作

- 选择“货架 / 自动炮台 / 冷柜 / 监控”；
- 点击九宫格空位建造；
- 点击已建设施升级；
- 点击“加固门”修复并提高卷帘门上限；
- 每局一次“应急断电”，震退并冻结全部敌人。

## 三种联动

- 相邻货架：黄金货道，提高收入；
- 炮台相邻监控：锁定激光，提高伤害并穿透；
- 冷柜相邻监控：冷链监控，更频繁、更长时间冻结全场。

## 推荐首次布局

把监控放在中心格，炮台和冷柜贴着监控，两个货架彼此相邻。这个布局能同时体验三种联动；之后再尝试更贪经济或更重防御的路线。

## 验证重点

不要只问“好不好玩”，观察：

- 10 秒内是否理解目标；
- 第一次收入到账后，是否纠结继续经济还是补防御；
- 门进入红线时是否产生紧张；
- 形成联动后是否感到明显质变；
- 失败后能否说出自己的错误并主动重开。

## 运行

直接打开 `index.html`，或使用静态服务器：

```bash
python3 -m http.server 8080
```
